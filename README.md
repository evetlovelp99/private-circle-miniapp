# 私密小圈子小程序

## 已实现能力

**第一版（MVP）**
- 邀请码进入（一次性）/ 首次「创建圈子」无障碍进入
- 图文动态发布
- 首页私密动态流
- 点赞、评论

**第二版（已加）**
- 语音动态：按住说话（AAC），列表与详情可播放（云存储临时链接）
- **视频**：相册或拍摄一段视频（最长约 300 秒），可选微信生成的封面缩略图上传
- **实况**：先选一张**封面原图**，再选一段**动态短视频**（≤60 秒）；列表用封面做海报播放动态（与系统相册里长按的「实况」不是同一 API，属于两段素材拼接）
- 删除动态：作者本人与创建者均可删，并级联删掉该条的点赞与评论
- 成员管理：列出所有通过你发出的邀请绑定关系的成员；一键静默切断（仍保留管理页手写 openid 方式）
- 静默时间线切断：与前一版逻辑一致，`canViewUntil` 只对「之后的新帖」生效

## 1. 运行前准备

1. 微信开发者工具导入本项目目录：`private-circle-miniapp`
2. 开通云开发并创建环境
3. `app.js` 里配置 `globalData.envId` 为你的云环境 ID
4. 在云开发中为云函数上传并部署（安装依赖）：
   - `auth`
   - `post`
   - `admin`
5. 每次拉取本仓库更新后，请再次 **重新部署** 以上云函数

## 2. 云数据库集合

请创建：
- `users`
- `inviteCodes`
- `relations`
- `posts`
- `likes`
- `comments`

帖子字段（云存储 fileID，可为空字符串）：  
`audio` 语音；`images` 图片数组；`video` / `videoThumb` 普通视频与封面；`liveMotion` 实况动态视频（实况封面放在 `images[0]`）。

## 3. 推荐索引

- `relations.ownerUserId`（列表成员：`where ownerUserId = 管理员`）
- `relations.ownerUserId + viewerUserId`
- `posts.authorId + createdAt`

## 4. 使用流程简述

1. 首次无任何用户：`邀请码页` → **我是创建者，创建圈子**
2. 创建者：`我的 → 管理` 生成一次性邀请码
3. `管理` 顶部 **成员管理**：查看已通过邀请进来的成员，或对某人 **停止对方看新动态**
4. 他人：输入邀请码进入，可见关系按产品设计过滤
5. 发布页：文字 / 图片 / **按住录音**（需授权麦克风）；至少选一种才可发布

## 5. 隐私与兼容

- 语音：`scope.record`
- 相册/摄像头（图片与视频）：需在隐私指引中说明 **相册**、**摄像头** 用途；真机首次会按微信策略弹出授权

若控制台提示隐私或权限相关告警，请到公众平台「用户隐私保护指引」补充对应说明，并在开发者工具里同步隐私配置。
